# 落ち物パズル

## 概要

2個1組の玉を操作する落ち物パズル
同じ色を一定数つなげて消し、得点を稼ぐゲーム

## 制作背景

- 「ツインビー対戦ぱずるだま」のこだまシステムに着想を得て制作
  原作の良さを残しつつ、ブラウザ環境で快適に遊べる形に再設計
  NEXT表示数の可変化など拡張要素を追加
- 現在では画質やアスペクト比の問題で長時間プレイが難しいため、現代のブラウザ環境で快適に遊べる
  落ち物パズルとして再構築した

## こだわり・工夫点

### ゲーム設計

- こだま挙動の再現
- ネクネクネク（三つ先のNEXT）の表示
- 細かい値を変更することで、難易度を調整できること

### 制作

- 実装はChatGPTを活用
- 仕様設計と挙動検証は自身で
- ロジックを理解した上で整理・修正

## 遊び方

- 上から2個1組の玉が落下
- 同じ色を指定数以上つなげると消える
- たまが出現位置が塞がるとゲームオーバー

### 操作方法

- 左右移動：左右の矢印キー
- 右回転：x キー
- 左回転：z キー
- ソフトドロップ：下矢印キー（速く落とせる）
- ハードドロップ：上矢印キー（即座に落下＆固定）

### 玉の種類について

- おおだま
  同じ色を指定値(初期値3)以上つなげると消える
- こだま
  隣でおおだまが消えるとおおだまに変化
  こだまはいくらつなげても消えない

### 消える条件

- 同じ色が指定値(初期値3)以上つながる
- 横・縦・かぎ型に繋がった玉が消える
- 斜めは消えない

### NEXT

次に落ちてくるたまが指定値(初期値3)先まで表示

### ゴースト

現在のたまがどこに落ちるかを薄く表示
落下位置の目安として使用

### ゲームオーバー

- たまの出現位置が塞がれ、次のたまが落下できなくなるとゲームオーバー
- 盤面端が上まで積み上がっても問題はない

## スコア計算

- 消した玉の個数 ×（連鎖ボーナス + 連結ボーナス + 色数ボーナス）×10
- ボーナス値は調整可能な定数として管理

### 連鎖ボーナス

1連鎖 0
2連鎖 8
3連鎖 16
4連鎖 32
5連鎖 64
6連鎖以降 段階的に増加（最大19連鎖 512）

### 連結ボーナス

3個 0
4個 2
5個 3
6個 4
7個 5
8個 6
9個 7
10個以上 10

### 色数ボーナス

1色 0
2色 3
3色 6
4色 12

## ゲームルールの変更・調整について

JSの先頭にまとめて定義

### 全何色で遊ぶか

最大5 初期及びおすすめは4

```js
//この値を変更する
const COLORS = 4;
```

### 何個つながったら消えるか

こだまの概念があるため、3以下がおすすめ
こだまの出現確率を下げる（おおだまの出現確率を上げる）と4でもいい

```js
//この値を変更する
const ERASE_COUNT = 3;
```

### NEXT表示数

減らせば減らすほど先が読めなくなるため、難易度が上がる
初期値は3
見易さ的には最大値6

```js
//この値を変更する
const NEXT_COUNT = 3;
```

### おおだまの出現率

0～1で設定
1にするとこだまが出現しなくなる
初期値は0.6（六割）

```js
//この値を変更する
const BALL_RATE = 0.6;
```
